1. نظرة عامة على المشروع (Executive Summary)

يعد نظام ماجيستك لإدارة الفنادق منصة سحابية شاملة مصممة لإدارة وتشغيل سلاسل الفنادق الفاخرة. يدمج النظام بين عمليات إدارة الغرف متعددة المباني، محرك التسعير الديناميكي والموسمي، دورة حياة الحجوزات، الدفاتر المالية وسجلات المصروفات، طبقات ذكاء الأعمال ومؤشرات الأداء الرئيسية (KPIs)، بالإضافة إلى مساعد ذكي باللغة العربية (n8n AI Concierge) يعمل على مدار الساعة.

3. بنية قاعدة البيانات وملفات الـ Seeds

تم تصميم وتنفيذ نموذج بيانات موسع على Supabase يشمل:

  • المباني والغرف: 3 مبانٍ رئيسية (المبنى الرئيسي، جناح رويال، بيتش فيو) بإجمالي 75 غرفة مصنفة (ديلوكس، أجنحة عائلية، جناح ملكي بانورامي).
  • العملاء والحجوزات: 530 عميل مسجل و2,100 حجز تاريخي ومستقبلي (2024-2026) مع تتبع كامل لدورة حياة الحجز والنزلاء المسجلين.
  • محرك الأسعار والمواسم: تسعير ديناميكي حسب الفئات العمرية (كبار، مراهقين، أطفال، رضع) والمواسم (منخفض، معتدل، صيفي، ذروة الأعياد).
  • الدفاتر المالية: سجلات المدفوعات، حركات الاسترداد، ومصروفات التشغيل (رواتب، صيانة، مرافق).

4. طبقات مؤشرات الأداء والتحليلات (KPI Analytics Layer)

تتضمن قاعدة البيانات 5 طبقات تحليلية برمجية بالـ SQL:

  • الطبقة الأولى (Executive KPIs): حساب RevPAR (العائد لكل غرفة متاحة)، ADR (متوسط السعر اليومي)، نسب الإشغال، وقائمة الدخل والأرباح الشهرية (P&L).
  • الطبقة الثانية (Customer & Channels): تحليل شرائح العملاء وفق نموذج RFM (العملاء الذهبيين، المترددين، المهددين بالفقدان) وتحليل قنوات الحجز (Booking.com، مباشر، إكسبيديا).
  • الطبقة الثالثة (Predictive & Pricing): العائد على الحملات الترويجية، فترات الحجز المسبق (Lead Time)، ومرونة الأسعار الموسمية.
  • الطبقة الرابعة (Inventory & Real-Time Quotes): دوال SQL لحساب عروض الأسعار والتوافر الفوري وفق تواريخ الإقامة وأعمار النزلاء.

5. تفاصيل نشر الباك إيند وحل مشكلات الخادم (MonsterASP.NET)

تم نشر مشروع الـ Web API على MonsterASP.NET كخيار مجاني 100% يدعم .NET 8 دون طلب بطاقة ائتمانية.

إعداد ملف web.config لدعم طلبات CORS:

<?xml version="1.0" encoding="utf-8"?>
<configuration>
  <location path="." inheritInChildApplications="false">
    <system.webServer>
      <handlers>
        <remove name="OPTIONSVerbHandler" />
        <add name="aspNetCore" path="*" verb="*" modules="AspNetCoreModuleV2" resourceType="Unspecified" />
      </handlers>
      <aspNetCore processPath="dotnet" arguments=".\HotelManagement.Api.dll" stdoutLogEnabled="false" stdoutLogFile=".\logs\stdout" hostingModel="inprocess" />
    </system.webServer>
  </location>
</configuration>

إضافة <remove name="OPTIONSVerbHandler" /> منعت خادم IIS من حظر طلبات الـ Preflight (OPTIONS) القادمة من نطاق Vercel، مما حل مشكلة اتصال الواجهة الأمامية بالباك إيند بشكل نهائي.

7. سجل حل المشاكل الفنية (Troubleshooting Log)

المشكلة السبب الجذري الحل المطبق
طلب بطاقة ائتمان على Render يتطلب Render بطاقة بنكية للتحقق من حاويات Docker. تم الانتقال إلى MonsterASP.NET (.NET 8 مجاني دون بطاقة).
خطأ 500 على خادم MonsterASP الملفات كانت داخل wwwroot بدلاً من Home وweb.config مفقود. نقل الملفات للـ Home وإنشاء web.config وربط Supabase.
حظر CORS Preflight خادم IIS يعترض طلبات OPTIONS قبل وصولها لـ .NET Core. إضافة remove OPTIONSVerbHandler في web.config.
شاشة بيضاء على Vercel نقص import useAuth في Layout.tsx. استعادة الـ import ودفع commit d168c43 لـ GitHub.
تحديث رابط الـ n8n Webhook تحديث نطاق n8n إلى seera.app.n8n.cloud. تحديث الكود ودفع commit 6691217 ونشره على Vercel.
